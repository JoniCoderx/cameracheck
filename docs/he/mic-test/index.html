    עוד בדיקות חינמיות

    איך בודקים מיקרופון

    1. לחצו על "בדיקת מיקרופון" ואשרו גישה למיקרופון.
    2. בחרו את המיקרופון מהרשימה הנפתחת אם יש לכם יותר מאחד.
    3. דברו בעוצמה הרגילה שלכם וצפו במד ובצורת הגל.
    4. לחצו על "הקלטה 5 שנ׳" ואז השמיעו את הקטע כדי לשמוע בדיוק מה שאחרים שומעים.

    מהי עוצמת מיקרופון טובה?

    כוונו לשיאים בין −20 dB ל־−10 dB בזמן דיבור רגיל. מתחת ל־−45 dB הצד השני יתקשה לשמוע אתכם: התקרבו או הגבירו את הגבר הקלט (Gain). אם המד מגיע שוב ושוב לאזור האדום ליד 0 dB, הקול ייחתך ויישמע צורם – הנמיכו את ההגבר או הרחיקו מעט את המיקרופון.

    הערך "תדר דומיננטי" מציג את הצליל החזק ביותר שהמיקרופון קולט. רוב הקולות נמצאים בין 85 Hz ל־255 Hz. קריאה קבועה של 50 Hz או 60 Hz כשאף אחד לא מדבר מעידה בדרך כלל על זמזום חשמלי מכבל או מספק כוח.

    המיקרופון לא עובד? נסו את זה

    • הרשאת דפדפן: לחצו על סמל המנעול בשורת הכתובת ← מיקרופון ← אישור, ורעננו את הדף.
    • Windows 10/11: הגדרות ← מערכת ← קול ← קלט. בחרו את המיקרופון ובדקו את "עוצמת הקלט". פתחו גם הגדרות ← פרטיות ואבטחה ← מיקרופון והפעילו גישה לאפליקציות שולחן העבודה ולדפדפן שלכם.
    • macOS: הגדרות המערכת ← פרטיות ואבטחה ← מיקרופון ← הפעילו את הדפדפן. אחר כך הגדרות המערכת ← צליל ← קלט כדי לבחור התקן ועוצמת קלט.
    • iPhone / iPad: הגדרות ← Safari (או Chrome) ← מיקרופון ← לאפשר.
    • Android: לחיצה ארוכה על סמל הדפדפן ← פרטי האפליקציה ← הרשאות ← מיקרופון ← אישור.
    • אוזניות: בדקו את מתג ההשתקה על הכבל, וודאו שהתקע נמצא בשקע המיקרופון (הוורוד) או שאתם משתמשים במחבר TRRS בעל 4 מגעים.
    • אוזניות Bluetooth: חלקן עוברות למצב "דיבורית" באיכות נמוכה כשהמיקרופון פעיל. זו התנהגות רגילה, לא תקלה.

    טיפים לסאונד ברור יותר בשיחות

    • החזיקו את המיקרופון 10–20 ס״מ מהפה ומעט בצד כדי למנוע נשיפות.
    • השתמשו ב"לשמוע את עצמי" עם אוזניות כדי לעקוב אחרי רעשי רקע בזמן אמת.
    • ריהוט רך כמו וילונות, שטיחים וספה מפחית הד הרבה יותר מכל פילטר תוכנה.
    • השאירו את ביטול ההד והפחתת הרעשים פעילים בשיחות; כבו אותם רק בהקלטת מוזיקה.

    שאלות נפוצות

    איך יודעים אם המיקרופון עובד?

    התחילו את הבדיקה ודברו. אם מד העוצמה וצורת הגל זזים עם הקול והסטטוס הופך לירוק, המיקרופון עובד. הקליטו קטע של 5 שניות והשמיעו אותו כדי לבדוק את האיכות.

    למה המיקרופון שלי כל כך שקט?

    כנראה שהגבר הקלט נמוך. הגבירו את עוצמת הקלט בהגדרות הקול של מערכת ההפעלה, התקרבו למיקרופון ובדקו שבחרתם את ההתקן הנכון ברשימה.

    למה המיקרופון קולט הד?

    בדרך כלל הרמקולים חוזרים לתוך המיקרופון. השתמשו באוזניות, הנמיכו את עוצמת הרמקולים והשאירו את ביטול ההד פעיל באפליקציית השיחות.

    אפשר לבדוק מיקרופון USB או Bluetooth?

    כן. חברו אותו, לחצו על רענון ברשימת ההתקנים אם צריך, ובחרו אותו מהרשימה הנפתחת של המיקרופונים.

    אפשר להוריד את הקלטת הבדיקה?

    כן. אחרי ההקלטה לחצו על הורדה כדי לשמור את הקטע. הוא נוצר בדפדפן שלכם ולעולם לא מועלה.
