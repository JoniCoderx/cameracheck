スピーカー・ヘッドホンのテスト方法

  1. システムの音量を、心地よい小さめのレベルに設定します。
  2. 「左」、次に「右」を押します。それぞれの音がその側からだけ聞こえればOKです。
  3. 「両方」を押して、音が中央に定位するか確認します。
  4. 周波数スイープを再生して、重低音から高音までの範囲を聴きます。

左右が逆・片側から聞こえない？

左のトーンが右から聞こえる場合は、ヘッドホンを逆に着けているか、ケーブルや変換アダプターの配線が逆になっています。片側が無音なら、サウンド設定のバランスを確認し（Windows：設定 → システム → サウンド → 使用中のデバイス → 左/右、macOS：システム設定 → サウンド → 出力 → バランス）、別のケーブルや端子も試してください。

スマホやノートPCの中にはモノラルスピーカーが1つしかないものもあります。その場合は左も右も同じ場所から聞こえますが、それで正常です。

周波数スイープと聴力

若い人は一般に約 20 Hz〜20 kHz の音を聞き取れます。上限は年齢とともに下がり、多くの大人は 14〜16 kHz より高い音が聞こえなくなります。ノートPCやスマホの小さなスピーカーは 100〜150 Hz 以下の音をほとんど再生できないことが多く、聴力に問題がなくてもスイープの最初が無音になることがあります。高い周波数の音は不快に感じることがあるので、音量は小さめにしてください。

まったく音が出ない？

  • システムとブラウザタブがミュートになっていないか確認します。タブに斜線入りのスピーカーアイコンがないか見てください。
  • 正しい出力デバイスが選ばれているか確認します（Bluetoothヘッドホンが自動で切り替わっていることがよくあります）。
  • 有線ヘッドホンは抜き差しし、Bluetoothヘッドホンはペアリングし直します。
  • iPhoneではサイレントモードをオフに。Androidでは着信音ではなくメディアの音量を上げます。

よくある質問

左右のスピーカーをテストするには？

「左」ボタンを押すと、左側だけからトーンが鳴るはずです。次に「右」を押します。逆になっている場合はヘッドホンを付け直すか、ケーブルやバランス設定を確認してください。

高い周波数が聞こえないのはなぜ？

15 kHz を超える音の聴力は年齢とともに自然に低下します。また小型スピーカーの多くは非常に高い音や低い音を再生できません。どちらも正常です。

テスト音は耳に安全ですか？

通常の音量なら安全です。特にヘッドホンでは、システム音量を小さめにして始め、少しずつ上げてください。

Bluetoothヘッドホンでも使えますか？

はい。先に接続して出力デバイスにしてから、トーンを再生してください。
