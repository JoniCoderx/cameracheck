Webカメラが映らない・真っ黒になる

更新日 2026年11月5日 · 3 分で読めます

ステップ0：Webカメラテストを実行する

このサイトのWebカメラテストを開始します。「カメラが見つからない」「許可がブロックされている」「カメラが使用中」、または実際の解像度とフレームレート付きで映像が表示される、のどれかがはっきりわかります。その結果に合わせて、下の対処法に進んでください。

1. プライバシーシャッターを開ける

多くのノートPC（Lenovo、HP、Dell）には、画面の上に小さなスライド式のカバーがあります。側面にカメラのオフスイッチがある機種や、カメラアイコンのファンクションキーがある機種もあります。シャッターが閉じていると、カメラは正常と表示されたまま、映像は黒やグレーになります。

2. カメラを使っているほかのアプリを閉じる

Windowsでは、ほとんどのWebカメラは同時に1つのアプリでしか使えません。Zoom、Teams、Skype、OBS、カメラアプリ、ビデオ通話中のほかのブラウザータブを閉じてから、テストを再読み込みしてください。

3. カメラへのアクセスを許可する

  1. Windows：設定 → プライバシーとセキュリティ → カメラ。「カメラへのアクセス」「アプリがカメラにアクセスできるようにする」「デスクトップ アプリがカメラにアクセスできるようにする」をオンにします。
  2. Mac：システム設定 → プライバシーとセキュリティ → カメラ で、ブラウザーと通話アプリをオンにします。
  3. ブラウザー：アドレスバーの横の鍵アイコンをクリックし、カメラを「許可」にして再読み込みします。

4. ケーブルとポートを確認する（USB Webカメラ）

ハブやモニターのUSBポートではなく、PCに直接挿し、別のポートも試してください。混み合ったUSBポートにつないだ1080pのWebカメラは、接続はされても映像が届かないことがあります。

5. 解像度を下げる

1080pや4Kのときだけ映像が止まる、または真っ黒になる場合は、テストで720pに切り替えてください。それで映るなら、カメラかUSB接続が高い設定に追いついていません。

6. カメラのドライバーを再インストールする（Windows）

  1. スタートを右クリック → デバイス マネージャー。
  2. 「カメラ」（または「イメージング デバイス」）を開きます。
  3. Webカメラを右クリック →「デバイスのアンインストール」を選び、再起動します。起動時にWindowsが新しいドライバーを入れます。
  4. カメラが一覧にまったくない場合は、「操作」→「ハードウェア変更のスキャン」を選びます。

FPSが低い、映像が暗くてザラつく

Webカメラは暗い場所では、1コマごとの露出を長くするためにフレームレートを下げます。背後ではなく自分の正面にライトを置くと、たいていFPSは30に戻ります。レンズも拭いてください。映像がぼやける原因で一番多いのはレンズの汚れです。

よくある質問

あるアプリではWebカメラが映るのに、別のアプリで映らないのはなぜですか？

カメラはアプリごとに選ばれます。そのアプリのビデオ設定を開き、Webカメラを名前で選んでください。ほかのアプリがカメラを使っていないかも確認しましょう。

Webカメラの映像が左右反転しているのはなぜですか？

プレビューは鏡のように見えるよう左右反転して表示されます。通話相手には正しい向きで映っています。
