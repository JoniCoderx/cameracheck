    オンラインでマイクとWebカメラをテストする方法

    MicNCamはマイク、Webカメラ、スピーカーをブラウザ上で直接チェックします。見出しの下のボタンを押し、ブラウザに確認されたらアクセスを許可するだけ。アプリのインストールもアカウント作成も必要ありません。

    1. 「すべてテスト」をクリックします（マイクやカメラだけのテストも可能です）。
    2. ブラウザから許可を求められたら「許可」を選びます。
    3. 普段どおりに話します。レベルメーターと波形が声に合わせて動くはずです。
    4. カメラのプレビューを見て、映像、解像度、フレームレートを確認します。
    5. 左右のトーンを再生して、スピーカーやヘッドホンが正常か確認します。

    結果の見方

    マイクメーターは、デバイスが取り込める最大値を基準にした入力音量をデシベル（dB）で表示します。無音は通常 −60 dB 以下、腕の長さほどの距離での普通の会話は −35〜−15 dB 程度で、0 dB に達すると音がクリップして割れて聞こえます。

    カメラの解像度（例：1280 × 720 や 1920 × 1080）は映像の精細さを示し、フレームレート（FPS）は動きの滑らかさを示します。ビデオ通話では 30 FPS が標準です。多くのWebカメラは暗い場所で 15 FPS に落ちるため、FPS が低いときは照明を足しましょう。

    Zoom、Teams、Google Meet、Discordの前にテスト

    大切な会議、面接、オンライン授業、配信の前にさっと確認しておけば、「聞こえてますか？」というお決まりのやり取りを避けられます。Zoom、Microsoft Teams、Google Meet、Skype、Discord、OBSで使う予定のマイクとカメラをここで選んでください。MicNCamで動作すればブラウザでは正常なので、残る問題はそのアプリ自体の音声・ビデオ設定にあります。

    マイクやカメラが使えない？すぐできる対処法

    • アクセスを許可：アドレスバー横の鍵またはカメラのアイコンをクリックし、カメラとマイクを「許可」にしてから再読み込みします。
    • 他のアプリを閉じる：Zoom、Teams、OBSや別のブラウザタブがカメラを占有していると、他から使えなくなります。
    • 正しいデバイスを選ぶ：プルダウンで内蔵、USB、Bluetoothのデバイスを切り替えます。
    • システムのプライバシー設定を確認：Windowsでは 設定 → プライバシーとセキュリティ → カメラ / マイク、macOSでは システム設定 → プライバシーとセキュリティ を開きます。
    • ハードウェアのスイッチを確認：多くのノートPCにはカメラシャッターやミュートキーがあり、ヘッドセットのケーブルにもミュートスイッチが付いていることがよくあります。
    • ドライバーの更新や再起動：単純な再起動で「デバイスが見つかりません」エラーの多くが解決します。

    プライバシーは安全？

    はい。すべて標準的なブラウザ技術（WebRTC getUserMedia と Web Audio API）を使ってローカルで動作します。音声や映像がサーバーに送信されたり、保存されたり、誰かに見られたりすることはありません。録音やスナップショットは、タブを閉じるかダウンロードするまでブラウザ内にだけ存在します。

    よくある質問

    このマイク・Webカメラテストは無料ですか？

    はい。完全無料で、登録不要、回数制限なし、インストールも必要ありません。

    音声や映像は録画・アップロードされますか？

    いいえ。すべてブラウザ内で処理されます。どのサーバーにもアップロード・保存されません。

    ブラウザから許可を求められません。どうすれば？

    アドレスバーのカメラまたは鍵のアイコンをクリックし、カメラとマイクを「許可」にしてページを再読み込みしてください。iPhoneでは 設定 → Safari → カメラ / マイク で「確認」または「許可」を選びます。

    カメラの画面が真っ黒なのはなぜ？

    他のアプリがカメラを使用中、プライバシーシャッターが閉じている、または選んだ解像度に非対応の可能性があります。他のアプリを閉じる、シャッターを開ける、別の解像度を試す、リストから別のカメラを選ぶなどしてください。

    iPhoneやAndroidでも使えますか？

    はい。iOSとAndroidのSafari、Chrome、Firefox、Edge、Samsung Internetで動作します。「カメラ切替」で前面と背面の両方のカメラをテストできます。

    対応ブラウザは？

    Chrome、Edge、Firefox、Safari、Opera、Brave、Samsung Internetなど最新のブラウザに対応しています。カメラとマイクを使うには、ページをHTTPSで開く必要があります。
