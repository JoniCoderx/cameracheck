Zoom 会議の前にマイクをテストする方法

  1. 「マイクテスト開始」を押し、マイクへのアクセスを許可します。
  2. 会議で使うマイクを選びます。
  3. 普段どおりに話します。メーターが緑のゾーンに届けばOKです。
  4. 短いクリップを録音し、ヘッドホンで聞き返します。

確認すべき Zoom のオーディオ設定

  • 設定 → オーディオ → マイク：マイクを名前で選び、「マイクのテスト」を押します。
  • 音量が勝手に変わる場合は、「マイク音量を自動調整」のチェックを外し、スライダーを自分で設定します。
  • 「背景雑音を抑制」は、ほとんどの部屋では「自動」で問題ありません。声が途切れる場合は「低」にします。
  • 音楽の演奏や楽器のレッスンをする場合は、「ミュージシャン向けのオリジナルサウンド」をオンにすると、Zoom が音声を加工しなくなります。

会議で誰にも声が聞こえない？

  • 左下のマイクアイコンを確認します。赤い斜線はミュート中という意味です。
  • マイクアイコンの代わりに「オーディオに参加」と表示されている場合は、クリックして「コンピューターオーディオで参加」を選びます。
  • ホストが全員をミュートしている可能性があります。チャットで尋ねるか「手を挙げる」を押しましょう。
  • Teams、Discord、別のブラウザタブなど、マイクを使う他のアプリを閉じてから再参加します。

よくある質問

Zoom 会議の前にマイクをテストするには？

このページのマイクテストを使うか、Zoom の 設定 → オーディオ →「マイクのテスト」を開きます。zoom.us/test ではテストミーティングも利用できます。

Zoom で「マイクが利用できません」と表示されるのはなぜ？

他のアプリがマイクを使っているか、Zoom に権限がない可能性が高いです。他の通話アプリを閉じ、OSのマイクのプライバシー設定で Zoom を許可してください。

Zoom で声が小さくなるのはなぜ？

OSの入力音量が低いか、Zoom の自動調整で音量が下げられています。入力音量を上げ、Zoom の自動調整のチェックを外してください。

このページは音声を録音・送信しますか？

いいえ。すべてブラウザ内で動作し、何もアップロードされません。
