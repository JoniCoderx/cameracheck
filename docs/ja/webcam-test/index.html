    Webカメラのテスト方法

    1. 「カメラテスト開始」をクリックし、カメラへのアクセスを許可します。
    2. カメラと確認したい解像度を選びます。
    3. 隅に表示されるバッジで、リアルタイムの解像度とFPSを確認します。
    4. スナップショットを撮るか短い動画を録画して、シャープさと色味をチェックします。

    解像度とFPSについて

    解像度は1フレームあたりの画素数です：640 × 480（480p）、1280 × 720（720p HD）、1920 × 1080（1080p フルHD）、3840 × 2160（4K）。テストでは選んだ解像度を要求し、カメラが実際に出力している解像度を表示します。1080p対応をうたうWebカメラでも、ブラウザやUSB帯域の制限によって720pに落ちることがよくあります。

    FPS（1秒あたりのフレーム数）は動きの滑らかさを表します。ビデオ通話では 30 FPS が標準で、60 FPS ならさらに滑らかです。ここで表示されるFPSはドライバーの申告値ではなく実際のフレームから測定しているため、相手に見えている映像をそのまま反映しています。

    カメラが映らない・画面が真っ黒？

    • Zoom、Teams、Skype、OBSやカメラを使っている他のタブを閉じてください。ほとんどのカメラは同時に1つのアプリでしか使えません。
    • 物理的なプライバシーシャッターを開けるか、ノートPCのカメラキー（F8、F10、Fn+Fキーなど）を押します。
    • Windows 10/11：設定 → プライバシーとセキュリティ → カメラ →「カメラへのアクセス」と「アプリにカメラへのアクセスを許可する」をオンにします。
    • macOS：システム設定 → プライバシーとセキュリティ → カメラ → ブラウザをオンにします。
    • iPhone / iPad：設定 → Safari → カメラ → 許可。Android：アプリ情報 → 権限 → カメラ。
    • 映像が固まる場合は解像度を下げ、USBカメラはハブを使わずパソコンに直接接続しましょう。

    ビデオ通話できれいに映るコツ

    • 窓や柔らかい照明のほうを向きましょう。逆光だとシルエットになってしまいます。
    • カメラを目の高さに合わせ、グリッドを使って目が上から3分の1のラインに来るようにします。
    • 夜にFPSが下がる？照明を足しましょう。Webカメラは暗いと露光時間を延ばすため、フレームレートが下がります。
    • レンズを拭く：映像が「ぼやける」「かすむ」原因で最も多いのは指紋です。

    よくある質問

    Webカメラが使えるか確認するには？

    「カメラテスト開始」をクリックしてアクセスを許可します。自分が映り、ステータスが緑になればカメラは正常です。バッジに実際の解像度とFPSが表示されます。

    映像が左右反転しているのはなぜ？

    前面カメラは鏡のように自然に感じられるよう、標準で左右反転して表示されます。通話相手には反転していない映像が見えています。「反転」ボタンで切り替えられます。

    WebカメラのFPSが低いのはなぜ？

    主な原因は暗さ、USBポートの混雑、高すぎる解像度です。照明を足す、720pを選ぶ、カメラをパソコンに直接つなぐなどを試してください。

    スマホの前面・背面カメラもテストできますか？

    はい。スマホでこのページを開き、「カメラ切替」をタップすると前面と背面のカメラを切り替えられます。

    撮影した画像はアップロードされますか？

    いいえ。スナップショットや動画はブラウザ内で作成され、ダウンロードしない限り保存されません。
