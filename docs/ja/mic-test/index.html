    マイクのテスト方法

    1. 「マイクテスト開始」をクリックし、マイクへのアクセスを許可します。
    2. マイクが複数ある場合は、プルダウンから使うマイクを選びます。
    3. 普段の声の大きさで話し、メーターと波形を確認します。
    4. 「5秒録音」を押してから再生し、相手に聞こえている音をそのまま確認します。

    適切なマイク音量の目安は？

    普通に話したときのピークが −20 dB〜−10 dB に収まるのが目安です。−45 dB を下回ると相手は聞き取りにくくなるので、マイクに近づくか入力ゲインを上げてください。メーターが 0 dB 付近の赤いゾーンに何度も触れる場合は音がクリップして耳障りになるので、ゲインを下げるかマイクを少し離しましょう。

    「主要周波数」の値は、マイクが拾っている最も強い音の高さを示します。ほとんどの人の声は 85 Hz〜255 Hz の範囲です。誰も話していないのに 50 Hz や 60 Hz で一定の値が出る場合は、ケーブルや電源からの電気的なハムノイズの可能性が高いです。

    マイクが使えない？試してほしいこと

    • ブラウザの許可：アドレスバーの鍵アイコン → マイク → 許可 にしてから再読み込みします。
    • Windows 10/11：設定 → システム → サウンド → 入力。マイクを選び「入力音量」を確認します。また 設定 → プライバシーとセキュリティ → マイク を開き、デスクトップアプリとブラウザのアクセスをオンにします。
    • macOS：システム設定 → プライバシーとセキュリティ → マイク → ブラウザをオンにします。次に システム設定 → サウンド → 入力 でデバイスと入力音量を選びます。
    • iPhone / iPad：設定 → Safari（または Chrome）→ マイク → 許可。
    • Android：ブラウザのアイコンを長押し → アプリ情報 → 権限 → マイク → 許可。
    • ヘッドセット：ケーブルのミュートスイッチを確認し、プラグがマイク（ピンク）端子に挿さっているか、4極TRRSコネクタを使っているか確認します。
    • Bluetoothヘッドセット：マイク使用中は低音質の「ハンズフリー」モードに切り替わる機種があります。これは故障ではなく正常な動作です。

    通話の音をクリアにするコツ

    • ポップノイズを防ぐため、マイクは口から10〜20cm離し、少し斜めに向けます。
    • ヘッドホンをつけて「自分の声を聞く」を使うと、周囲の雑音をリアルタイムで確認できます。
    • カーテン、ラグ、ソファなどの柔らかい家具は、どんなソフトウェアフィルターよりも反響を抑えてくれます。
    • 通話ではエコーキャンセルとノイズ抑制をオンのままに。オフにするのは音楽を録音するときだけにしましょう。

    よくある質問

    マイクが正常に動作しているか確認するには？

    テストを開始して話してください。レベルメーターと波形が声に合わせて動き、ステータスが緑になればマイクは正常です。5秒間録音して再生すれば音質も確認できます。

    マイクの音が小さいのはなぜ？

    入力ゲインが低い可能性があります。OSのサウンド設定で入力音量を上げ、マイクに近づき、プルダウンで正しいデバイスを選んでいるか確認してください。

    マイクがエコーを拾うのはなぜ？

    多くの場合、スピーカーの音がマイクに回り込んでいます。ヘッドホンを使い、スピーカー音量を下げ、通話アプリのエコーキャンセルをオンにしておきましょう。

    USBやBluetoothのマイクもテストできますか？

    はい。接続したら必要に応じてデバイス一覧の「更新」を押し、マイクのプルダウンから選んでください。

    テスト録音はダウンロードできますか？

    はい。録音後に「ダウンロード」を押すと保存できます。音声はブラウザ内で作成され、アップロードされることはありません。
