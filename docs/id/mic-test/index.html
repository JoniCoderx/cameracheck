    Cara tes mikrofon

    1. Klik "Mulai tes mic" dan izinkan akses mikrofon.
    2. Pilih mikrofon Anda dari menu drop-down jika ada lebih dari satu.
    3. Bicaralah dengan volume normal dan perhatikan meter serta gelombang suaranya.
    4. Tekan "Rekam 5 dtk", lalu putar ulang klipnya untuk mendengar persis apa yang didengar orang lain.

    Berapa level mikrofon yang bagus?

    Usahakan puncaknya berada di antara −20 dB dan −10 dB saat berbicara normal. Di bawah −45 dB lawan bicara akan sulit mendengar Anda: mendekatlah atau naikkan gain input. Jika meter terus menyentuh zona merah dekat 0 dB, suara Anda akan clipping dan terdengar kasar, jadi turunkan gain atau jauhkan mic sedikit.

    Nilai "Frekuensi dominan" menunjukkan nada terkuat yang ditangkap mic. Kebanyakan suara manusia berada di antara 85 Hz dan 255 Hz. Angka tetap di 50 Hz atau 60 Hz saat tidak ada yang berbicara biasanya menandakan dengung listrik dari kabel atau adaptor daya.

    Mikrofon tidak berfungsi? Coba ini

    • Izin browser: klik ikon gembok di bilah alamat → Mikrofon → Izinkan, lalu muat ulang.
    • Windows 10/11: Pengaturan → Sistem → Suara → Input. Pilih mic Anda dan periksa "Volume input". Buka juga Pengaturan → Privasi & keamanan → Mikrofon dan aktifkan akses untuk aplikasi desktop dan browser Anda.
    • macOS: Pengaturan Sistem → Privasi & Keamanan → Mikrofon → aktifkan browser Anda. Lalu Pengaturan Sistem → Suara → Input untuk memilih perangkat dan level input.
    • iPhone / iPad: Pengaturan → Safari (atau Chrome) → Mikrofon → Izinkan.
    • Android: tekan lama ikon browser → Info aplikasi → Izin → Mikrofon → Izinkan.
    • Headset: periksa sakelar mute di kabel, dan pastikan colokan masuk ke jack mic (merah muda) atau Anda memakai konektor TRRS 4-pole.
    • Headset Bluetooth: beberapa beralih ke mode "hands-free" berkualitas rendah saat mic aktif. Itu perilaku normal, bukan kerusakan.

    Tips suara lebih jernih saat panggilan

    • Jaga jarak mic 10–20 cm dari mulut dan sedikit menyamping untuk menghindari suara letupan.
    • Gunakan "Dengar suara saya" dengan headphone untuk memantau bising latar secara real-time.
    • Barang lembut seperti gorden, karpet, dan sofa mengurangi gema jauh lebih baik daripada filter software apa pun.
    • Biarkan peredam gema dan peredam bising aktif saat panggilan; matikan hanya untuk merekam musik.

    Pertanyaan yang sering diajukan

    Bagaimana cara tahu mikrofon saya berfungsi?

    Mulai tes dan berbicaralah. Jika meter level dan gelombang suara bergerak mengikuti suara Anda dan status berubah hijau, mic Anda berfungsi. Rekam klip 5 detik dan putar ulang untuk memastikan kualitasnya.

    Kenapa suara mic saya pelan sekali?

    Gain input kemungkinan rendah. Naikkan volume input di pengaturan suara sistem operasi Anda, dekatkan diri ke mic, dan pastikan Anda memilih perangkat yang benar di menu drop-down.

    Kenapa mikrofon saya menangkap gema?

    Biasanya suara dari speaker masuk kembali ke mic. Gunakan headphone, kecilkan volume speaker, dan biarkan peredam gema aktif di aplikasi panggilan Anda.

    Bisakah saya mengetes mikrofon USB atau Bluetooth?

    Bisa. Sambungkan, tekan Muat ulang di daftar perangkat jika perlu, lalu pilih dari menu drop-down mikrofon.

    Bisakah saya mengunduh rekaman tes saya?

    Bisa. Setelah merekam, tekan Unduh untuk menyimpan klipnya. Klip dibuat di browser Anda dan tidak pernah diunggah.
